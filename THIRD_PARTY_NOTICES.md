# Third-Party Notices

Breath contains no third-party code, libraries, frameworks, web fonts, or
bundled media assets.

- All sound is synthesized at runtime with the Web Audio API. There are no audio
  files in this repository.
- All visuals are drawn procedurally on an HTML canvas. The only image assets are
  the app icons in `icons/`.
- The app makes no external network requests and loads no remote resources.
- Type is rendered with the operating system's own font stack (for example
  -apple-system, Segoe UI, Roboto). No web fonts are downloaded or bundled.
